# 2026-02-21

## Rewind philosophy: goal-driven autonomous tasks + heartbeat/proactivity
- Desire: make Rewind/OpenClaw less reactive and more proactive: given goals, it should propose daily tasks that move the user closer to them (inspired by ZeroClaw heartbeat-style proactive loops).
- But autonomy must be **earned** gradually via trust-building stages.

### Core constraints / philosophy (user-specified)
1) **Trust is earned incrementally**
   - Start with safe, mundane, reviewable actions.
   - Prefer drafts over sends: e.g., draft an email for review rather than sending it.
2) **Transparency & user awareness**
   - Users need to see what was done; agents can feel “too fast.”
   - Don’t slow agents down—make them track work clearly (logs/board/checklists) and surface summaries.
3) **Accessibility**
   - Proactive helpers must be available/reachable reliably (not only when the user remembers).
4) **Humans are dynamic / resistant**
   - People set alarms and later resent them (snooze/curse waking up).
   - Rewind should expect resistance and remain resilient because the aim is long-term wellbeing.

### Implementation direction hinted
- Adopt a heartbeat-like prompt/workflow: daily generation of a small set of tasks, executed within safety constraints, tracked, and reviewed.
- Bake these principles as core Rewind philosophies (proactivity with guardrails).
